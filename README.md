# my personal site

my personal site, built with TypeScript, React, Vite, Tailwind CSS, HTML, and CSS.

## local development

```bash
npm install
npm run dev
```

## checks

```bash
npm run lint
npm run build
```

## writing

Create a local draft with:

```bash
npm run new:post -- "My post title"
```
