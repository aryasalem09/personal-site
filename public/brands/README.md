# Brand asset sources

These marks appear only as descriptive organization identifiers in Arya Salem's portfolio. Preserve their proportions, colors, and clear space. Trademark ownership remains with each organization.

| File | Official source | Usage note |
| --- | --- | --- |
| `texas-am.svg` | [Texas A&M Brand Toolbox](https://marcomm.tamu.edu/template/logo-downloads/) | Texas A&M limits general logo use and asks non-faculty/staff users to seek approval. Keep the registered mark and approved proportions. |
| `ut-austin.svg` | [UT Austin University and CSU Wordmarks](https://umac.utexas.edu/brand-center/university-csu-wordmarks/) | Use the complete wordmark without cropping, recoloring, distortion, or effects. The shield alone requires approval. |
| `asa.png` | [American Statistical Association Graphic Standards](https://www.amstat.org/graphic-standards) | Non-ASA groups should request permission. At small sizes, the standards call for the ASA-only mark linked to ASA. |
| `tsa.png` | [Technology Student Association](https://tsaweb.org/) | Use is governed by TSA's current Branding Guide. Public permission scope is limited, so confirm before publication. |
| `mecc-labs-icon.jpg` | [MECC Labs](https://www.mecclabs.com/) | The official site provides no public reuse license. This is used descriptively in connection with Arya's stated co-founder role. |
